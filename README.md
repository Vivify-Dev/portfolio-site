# Portfolio Site

Simple one-page portfolio site for Jake Wiltse featuring ReelFinder, TaskNest, and FocusFlow.

## Run locally

1. Open a terminal in `/Portfolio-Site`
2. Start a static server:

```bash
npx --yes serve .
```

3. Open the local URL shown in the terminal

You can also open `index.html` directly in a browser for a quick preview.
